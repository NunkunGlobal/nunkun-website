# Nunkun — Global Solutions

Vercel-ready static website for Nunkun.

## Deploy

Upload the contents of this folder to a GitHub repository and import the repository into Vercel. No build command is required.

## Before launch

1. Replace `hello@nunkun.com` in `index.html` with Nunkun's real business email.
2. Add the real social links when available.
3. Replace portfolio mockups with genuine project screenshots as the project library grows.
4. Add proper individual service pages later if needed.
